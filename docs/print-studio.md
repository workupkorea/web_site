# WORKUP 전단 스튜디오

- 접속: `/admin/print-studio` — 워크업 사이트의 기존 관리자 로그인을 그대로 사용한다.
- 관리자 왼쪽 메뉴의 **전단 스튜디오**에서 새 창으로 연다. 같은 도메인에서 열려 별도 로그인이 필요 없다.
- **서버 저장 / 내 전단**: 사진·배치·문구·CMYK·재단선을 포함한 원본을 계정별로 저장하고 다른 PC에서 연다.
- **작업 저장 / 불러오기**: 기존 단일 HTML 작업 JSON 파일과 호환한다.
- **사진 → W주문 상품 검색**: 기존 암호화 계정 연동으로 조회 시점의 상품명·판매가·확대 사진을 읽는다.
- **저장된 상품 자료**: 2026-11-13에 확보한 상품 정보 21,666개와 이미지 연결 65개를 사용한다.

## 편집과 출력

12개 레이아웃, 칸 합치기·나누기, 줄별 칸 수·높이, 개별 상단 영역 편집, WORKUP 로고, Pretendard, 사진 확대·전체 적용, 상품 번호, 전체·부분 색상, 접었을 때 작게 표시되는 CMYK 피커, 재단선, CMYK PDF와 브라우저 인쇄를 제공한다. 자동 여백 자르기는 추가하지 않았다.

CMYK PDF는 이미지 기반 DeviceCMYK이며 인쇄소 ICC 프로파일은 포함하지 않는다. 재단선 포함을 켜면 해당 선은 PDF에 실제로 출력된다.

## 인증과 저장

페이지와 모든 전단 API는 기존 `getAdminMember()`로 관리자 상태를 확인한다. 쿠키를 다른 도메인으로 복사하거나 로그인 유효기간을 변경하지 않는다. 로그아웃하거나 기존 세션이 만료되면 다시 로그인해야 한다.

`supabase/migrations/20261113_print_studio.sql`은 적용된 상태다. `print_studio_projects`는 서버에서만 접근하고 원본은 비공개 `print-studio-private` 버킷에 보관한다. 서명된 URL로 직접 업로드하며 계정별 조회와 revision 비교로 다른 계정 접근 및 동시 편집 덮어쓰기를 방지한다.

상품 자료와 사진은 공개 저장소에 커밋하지 않는다. 같은 버킷의 `shared/` 아래 자료는 인증된 catalog 라우트로만 읽는다. 기존 `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `WJUMUN_CRED_KEY`와 기존 W주문 설정을 사용한다. 비밀번호나 서비스 키를 브라우저에 전달하지 않는다.

## 검증

```sh
node scripts/verify-print-studio.cjs
npx tsc --noEmit --incremental false
npm run build
```

타입 검사, 편집기 검사, 상품 파서와 이미지 URL 검증, 계정별 저장 경계 및 원본 충돌 검증을 통과했다. 미리보기 Next.js 빌드와 관리자 계정의 서버 저장도 확인했다.

운영 배포 후 기존 관리자 세션으로 메뉴 → 편집기 → W주문 검색 → 상품 넣기 → 서버 저장 → 내 전단에서 다시 열기를 확인한다. 로그아웃 상태의 editor/projects/products/catalog/image API는 401을 반환해야 한다. 브라우저 CMYK PDF 다운로드의 최종 확인은 별도 필요하다.
